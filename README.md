# 🧑‍🍳 셰프 마스터 (Chef Master)

초등 5학년 수학·영어 문제 풀이를 식당 경영 시뮬레이션의 "요리" 단계에 결합한 자기주도 학습 게임입니다.
별도 빌드 없이 정적 웹(HTML/CSS/Vanilla JS ES Modules)으로 동작하며, Firebase 키 없이도 localStorage 단독 모드로 플레이할 수 있습니다.

## 실행 방법

ES Modules를 쓰기 때문에 `index.html`을 더블클릭(file://)하면 동작하지 않습니다. 정적 서버로 여세요.

```bash
python3 -m http.server 8000
```

브라우저에서 `http://localhost:8000` 접속. GitHub Pages에 올리면 그대로 동작합니다(`.nojekyll` 포함).

## 개발 진행 현황

| 단계 | 내용 | 상태 |
|---|---|---|
| 1차 | 코어 영업 루프 (준비 → 영업 → 마감 정산), 파산 구제 알바 | ✅ 완료 |
| 2차 | 종업원 고용·일급 ✅ / 1~4호점 확장, 훈련, 레시피 Lv.10, 희귀 식재료 가챠, VIP, 건물주 | 🔨 진행 중 |
| 3차 | Firebase 로그인(학급코드+번호+이름), Firestore 저장, 친구 가게 방문, 3종 랭킹 | ⏳ 예정 |
| 4차 | 교사 대시보드 `admin.html` | ⏳ 예정 |

### 1차 구현 내용
- **영업 준비**: 오늘의 예보(맑음/비/추운 날/외국인 관광객/단체 손님), 식재료 구매(냉장고 칸 제한, 유통기한 없음, 자동 장보기), 4×4 홀 가구 배치(이동 무료), 냉장고 업그레이드(20→200칸)
- **영업(실시간 2분 30초)**: 손님 입장·주문·인내심 게이지, 주문 클릭 → 3문제 퀴즈
  - 퀴즈가 열리면 영업 시간과 모든 손님 인내심 **일시정지**, 문제당 30초 제한
  - 3정답 ★3 특상급(150% + 팁), 2정답 ★2 보통(100%), 1정답 이하 ★1 탄 요리(50%)
  - 오답 시 정답 + 1줄 해설 표시
  - 빈 그릇(쓰레기): 치우기 전엔 착석 불가, 방치 시간만큼 별점 하락
  - 진상 손님(2일차부터): 방치 시 다른 손님 인내심 2.5배 속도로 감소
  - 쓰레기·진상은 직접 클릭 처리(처리하는 동안 다른 작업 불가 = 시간 소모)
- **마감 정산**: 매출·팁·재료비·일당·순수익 결산표, 손님 리뷰 3~4개, 별점 변화, 자동 저장
- **파산 구제**: 재료도 돈도 없을 때만 [비상 설거지 알바] → 3문제 풀이 후 재기 자금 지급
- **퀴즈 엔진**
  - 수학: 지점별 난이도 자동 스케일링, 코드로 무한 생성 (사칙연산 → 혼합 계산 → 약수와 배수 → 약분과 통분 → 분수의 덧셈·뺄셈 → 분수의 곱셈 → 다각형의 넓이 → 평균). 오답 보기는 "흔한 실수"(혼합 계산을 앞에서부터 계산하기, 분모끼리 더하기 등)로 구성
  - 영어: 단어 뜻 맞히기(양방향), 빈칸 문장 완성, 스펠링 조합(타일/키보드)
  - 최근 15문제 중복 방지 큐, 영어 오답 우선 재출제(wrongQueue), 수학 취약 단원 우선 출제
  - 문제별 정답/오답 통계를 로컬에 저장(3·4차에서 `quizStats` 컬렉션으로 전송)
- **과목 비중**: 타이틀의 "로컬 모드 설정"에서 수학·영어 50:50 / 수학 100% / 영어 100% 선택 (학급 연결 후에는 교사 설정이 우선)

### 종업원 (2차 일부)
- 청소·서빙·경호 3개 역할 × 4등급(알바 → 전문가 → 베테랑 → 로봇). 역할마다 1명, 상위 등급을 고용하면 교체
- 계약금(고용 시 1회) + 일급(매일 마감 시 지급). 일급을 못 주면 비싼 직원부터 그만둠
- 청소: 이동속도·청소 시간·쓰레기 발생률 / 서빙: 손님 인내심·팁 보너스, 사장님 대신 배달 / 경호: 퇴치 확률(60~100%)·대응 시간·진상 등장률
- 직원이 없으면 사장님이 직접 청소하러 걸어감(요리 대기열에 함께 쌓임 = 시간 비용)

## 조작
- 마우스/터치: 손님 말풍선 클릭 → 요리, 🍽️ 클릭 → 치우기, 😡 클릭 → 진정
- 키보드: 보기 `1`~`4`, 스펠링은 알파벳 타자 / `Backspace`, `Enter`로 다음
- 개발 콘솔: `__chef.state`, `__chef.biz`, `__chef.applyClassControl({ isPaused: true })` (교사 일시정지 화면 미리보기)
